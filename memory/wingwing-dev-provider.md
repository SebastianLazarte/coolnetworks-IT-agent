**WingWing** es la empresa que actúa como **proveedor de desarrollo de software** de Maswer.

- Alcance: desarrollo a medida para Maswer (aplicaciones propias, proyectos de desarrollo).
- Implicación práctica: ante tickets o dudas de desarrollo (comportamiento de software a medida,
  entornos de desarrollo, bugs de aplicaciones propias de Maswer), **WingWing es el tercero
  responsable** — se encamina a ellos, no se trata como IT del día a día.

**Mapa de proveedores de Maswer:**
- **conet.de** → infraestructura de servidores + licencias M365 ([[conet-de-administers-maswer-infra]])
- **WingWing** → desarrollo de software
- **STAHLGRUBER** → STAkis, app de taller en Calden ([[starkis-external-vendor-calden]])
- **CoolNetworks / Sebastian** → IT remoto del día a día ([[user-identity]])
